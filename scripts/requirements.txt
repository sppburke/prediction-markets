# Python analytics-scripts dependencies (issue #366).

# Pinned so the CI Python drift-guard job (.github/workflows/ci.yml) and local runs use the
# same versions as the .venv-analysis env (Python 3.11). The ranking passes
# (rank_72hr_buyandhold.py, latency_shift_rerank.py via ranker_decay.py) and the new
# math test (test_ranker_decay.py) need numpy; the pandas-based passes also need pandas.
# The drift-guard test imports only ranker_decay (numpy); pandas is installed for the full

# duckdb (issue #375) powers the optional ranker read-layer (ranker_duck.py +

# falls back to SQLite if it is absent, but CI needs it to run the parity gate. Pinned to a
# version compatible with pandas 3.0 (1.1.3 rejects pandas' default `str` dtype on register).
numpy==2.4.4
pandas==3.0.3
duckdb==1.3.2
# scipy (issue #421) powers the ranker bake-off harness (scripts/ranker/): the reference
# estimator eb_shrinkage_skill uses scipy.stats.norm for the empirical-Bayes posterior tail.
# Pinned to a version whose cp311 wheel resolves against numpy 2.4 / pandas 3.0.
scipy==1.17.1
# arch (issue #421 PR2) provides Hansen-SPA (arch.bootstrap.SPA) and Romano-Wolf stepwise
# (arch.bootstrap.StepM) for grid-level deflation in scripts/ranker/oos_validation.py — used
# instead of hand-rolling the bootstrap multiple-testing. statsmodels is arch's dependency;
# both are pinned. cp311 wheels resolve against numpy 2.4 / pandas 3.0 / scipy 1.17.
arch==8.0.0
statsmodels==0.14.6
# numba JIT-compiles the AFML uniqueness_weights kernel (scripts/ranker/oos_validation.py) — the

# pure-Python loop (a test pins it), so it is a pure speedup. cp311 wheel resolves against numpy 2.4
# (numba 0.65 supports numpy up to 2.4); llvmlite is its pinned dependency.
numba==0.65.1
llvmlite==0.47.0
